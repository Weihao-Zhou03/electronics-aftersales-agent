# Chatwoot v4.19.0 源码契约核查

2026-10-21，开发时访问官方文档及固定 `v4.19.0` tag。此记录是静态源码核查，不是容器运行或真实集成通过证据。部署的 CE 镜像与实际结果另见 `chatwoot-compatibility.md`。

| 用途 | 固定版本证据与实现结论 |
|---|---|
| Bearer / bot 权限 | [AccessTokenAuthHelper](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/controllers/concerns/access_token_auth_helper.rb) 允许 bot 调用会话 show、toggle_status、messages create、assignments create；**不含 messages index**。独立配置 CHATWOOT_READ_ACCESS_TOKEN，仅 get_messages 使用专用非管理员客服账号；缺失时 bot 的读取错误必须显式暴露，不回退管理员凭据。该客服 token 没有原生方法级只读限制，由 adapter 限制用途。 |
| 账号权限 | [EnsureCurrentAccountHelper](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/controllers/concerns/ensure_current_account_helper.rb) 检查 bot 的 account 或已绑定 inbox 账号。运行时 adapter 额外校验固定 account/inbox，防止 bot 原生权限范围过宽。 |
| 会话详情 | [会话 partial](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/views/api/v1/conversations/partials/_conversation.json.jbuilder) 返回顶层 id（display_id）、account_id、inbox_id、status；`meta.assignee_type` 区分 User/AgentBot，`meta.assignee.id` 不可单独判断持有人。`meta.sender` 为 contact，`meta.hmac_verified` 来自本会话的 contact_inbox。 |
| 身份标识 | [Contact partial](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/views/api/v1/models/_contact.json.jbuilder) 包含 id、identifier。可信绑定必须同时匹配服务端登录用户标识及 `hmac_verified=true`，忽略 email/name/custom_attributes 作为身份依据。 |
| 显式交回 | [AssignmentService](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/services/conversations/assignment_service.rb) 接收 `assignee_type=AgentBot`，清除 User 指派、指派指定 bot 并设 pending，在同一个 Chatwoot 事务内完成。adapter 使用此路径，随后 GET 验证；本地员工显式授权由调用层保存。单独设 pending 无法证明已清除人工指派。 |
| 状态与人工接管 | [ConversationsController](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/controllers/api/v1/accounts/conversations_controller.rb) bot 从 pending 切 open 触发 bot_handoff；人工 User 打开会话时清除 AI 持有。adapter 发送前再次读取状态与指派。跨系统 GET/POST 仍有不可消除的竞态。 |
| bot 创建与绑定 | [InboxesController](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/controllers/api/v1/accounts/inboxes_controller.rb) 的绑定字段是 `agent_bot`。`GET inboxes/{id}/agent_bot` 的 [响应 envelope](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/views/api/v1/accounts/inboxes/agent_bot.json.jbuilder) 为 `agent_bot`。 |
| bot 凭据 | [AgentBot JSON](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/views/api/v1/models/_agent_bot.json.jbuilder) 管理员响应包含 `access_token` 和独立 `secret`；bot 列表是数组，详情为对象。bootstrap 要求实际字段存在，绝不自行生成冒充 Chatwoot secret。 |
| 账户 Webhook | [WebhooksController](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/controllers/api/v1/accounts/webhooks_controller.rb) 要求 body 的 `webhook` 对象；[响应 partial](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/views/api/v1/accounts/webhooks/_webhook.json.jbuilder) 包含 secret。列表为 `payload.webhooks`，创建/更新为 `payload.webhook`。bootstrap 仅订阅 conversation_status_changed / conversation_updated。 |
| 签名协议 | [Webhooks::Trigger](https://github.com/chatwoot/chatwoot/blob/v4.19.0/lib/webhooks/trigger.rb) 签名原始 JSON 请求体，header timestamp 原字符串加点，再拼 body；SHA256 HMAC 以 `sha256=` 前缀发送。Delivery 可选。所有回调走 SafeFetch，内网是否可达须实际测试。 |
| Sidekiq 与 bot 回调 | [AgentBotListener](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/listeners/agent_bot_listener.rb) 通过异步 AgentBots::WebhookJob，附 bot.secret 与 delivery UUID。Rails 首页可访问不证明此链路成功。 |
| Webhook / API 差异 | [Message](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/models/message.rb) 的 webhook 顶层 id 是 message ID；message_type 字符串；API push 可是整数。message webhook 的 account/inbox 是对象。 |
| 客户 sender 差异 | [Contact](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/models/contact.rb) 的 webhook_data **不含 type**，包含 contact_type；push_event_data 含 `type=contact`。[User](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/models/user.rb) webhook 的 type 是 `user`；[AgentBot](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/models/agent_bot.rb) 为 `agent_bot`。 |
| 控制事件 payload | [EventDataPresenter](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/presenters/conversations/event_data_presenter.rb) 的 webhook_data 顶层 account 对象、inbox_id、meta；meta.sender 来自 push_event_data，和 message 顶层 sender 形状有区别。 |
| Widget 强制 HMAC | [WebWidget](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/models/channel/web_widget.rb) 字段 hmac_mandatory，可经 inbox channel 更新；[Inbox JSON](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/views/api/v1/models/_inbox.json.jbuilder) 管理员可获取 hmac_token 与 website_token。bootstrap 禁用自动指派并 GET 确认 hmac_mandatory=true。 |
| 身份替换防护 | [Widget ContactsController](https://github.com/chatwoot/chatwoot/blob/v4.19.0/app/controllers/api/v1/widget/contacts_controller.rb) 校验 set_user 的 identifier_hash，也校验携带 identifier 的 update；验证成功后设置当前 contact_inbox.hmac_verified。退出撤权仍须由本项目服务端及 Widget.reset 配合验证。 |

公开文档同时参考：[绑定 AgentBot](https://developers.chatwoot.com/api-reference/inboxes/add-or-remove-agent-bot)、[指派会话](https://developers.chatwoot.com/api-reference/conversation-assignments/assign-conversation)、[Webhook 指南](https://app.chatwoot.com/hc/user-guide/articles/1677693021-how-to-use-webhooks)。本项目按固定 tag 明确的字段处理，真实字段不同即停止并更新兼容记录。
