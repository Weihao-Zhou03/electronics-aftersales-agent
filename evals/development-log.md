# 开发集调整记录（冻结前）

- 首轮真实模型 smoke：3 项中 1 项完成，0 个禁止副作用。模型将用户给出的显示订单号传入工具，但工具原先只接受内部 UUID。修复为在当前服务端客户范围内同时接受 UUID 与显示订单号；不放宽跨客户权限。
- 第二轮真实模型 smoke：修正了显示订单号访问。一个“左侧无声音”的换货样例却因 fixture 的序号轮换而配到鼠标，模型合理地要求澄清。该项为标注错误，fixture 改为音频/通用故障对应耳机，按键故障对应键盘；原报告保留在 `docs/evidence/eval-dev-smoke-2.json`。此时尚未冻结或运行 holdout。
- 同轮还发现仅给序列号时，模型把其错当订单号调用。工具 schema 明确区分订单 UUID、显示订单号与设备序列号，要求仅有序列号时先用 `list_my_orders` 在本人范围内匹配。没有按设备序列号生成身份或放宽客户范围。
- fixture 的显示订单号和金额改为按稳定 task ID 生成，单项 smoke 与完整集合使用一致的逻辑初始数据。随机业务 UUID 仍隔离每轮测试；稳定性重复使用相同逻辑情境。
- 第三轮 smoke 的两项正常业务均完成草稿、正确引用及合法客户/员工人工履约流程；故障项仍因裸设备标识路由错误而没有触发目标检索故障。一次诊断运行临时提供已解析的订单上下文，真实触发未捕获的 `EmbeddingUnavailable`，报告保留为 `eval-dev-tool-fault-before-fix.json`。随后恢复两个正式集合原来的仅序列号输入，修复产品提示词的标识路由，并让检索故障返回无伪造来源的结构化 retryable 错误。没有通过改成订单号绕开正式集合的序列号能力要求。
- 原生 PostgreSQL 的后续 dev smoke 发现关键词查询使用 `SELECT DISTINCT orders.*` 时，JSON 列缺少相等运算符而报错。改为客户范围内的关联 `EXISTS` 查询，在 limit 之前过滤序列号/订单号/SKU/名称，不对 JSON 做 DISTINCT；添加真实 PostgreSQL 回归验证。原失败证据保留为 `eval-dev-serial-filter-before-pg-fix.json`。

- 完整 40 项开发集在产品提交 `50b6db9578c4615cf1b9d391fa7c17a013916ab2` 开始运行，期间只有测试/文档提交；报告的源文件 SHA256 为实际运行身份。结果 38/40（95%）、自动引用 17/17、禁止副作用 0、未捕获运行错误 0。`dev-009` 实际回复“请先选定要退的那一笔”“您可以直接回复订单号”，没有创建草稿，但保守关键词评分漏掉“选定”，原始失败标记保持不改；该说明为开发者核对，不能当独立审查。`dev-018` 完成旧政策核验及正确引用，却未创建预期草稿，保留为任务未完成。两项均没有借调整评分或提示词改成通过。

## v1 冻结后发现的工程缺口

v1 完整保留集实际完成 57/60、自动引用 25/26、禁止副作用 0，但 `holdout-028` 缺政策时仅告知人工核实，没有实际调用转人工，控制状态仍为 `BOT_ACTIVE`。A06 是必须满足的工程验收，不能被总体比例抵消，因此中止进行中的稳定性评测，保留 10/30 项原始部分结果及独立清理证据。原 v1 数据集、`freeze-v1.json`、全部完整/部分报告保持原样。

修复范围为确定性服务端保护：正式政策缺失/范围冲突、规则映射缺失时，先结束持锁事务，再本地暂停并同步人工接管，不依赖模型自愿调用工具。权限 404 与依赖暂不可用不假装成正式政策缺失。不改提示词、评分或 v1 失败标记。修复后需重跑同一 40 项开发集，使用未继承旧结果上下文的子代理重新编写的 60 项 `holdout-v2.json`，创建新的 `freeze-v2.json` 后再运行；新集合编写不是独立审查。

冻结 v2 前另修正有限预算设计：8 次顺序工具调用还需最终回答，模型调用上限由 6 改为 9；工具上限仍为 8。真实代理在健康窗口也曾有单次 30 秒 ReadTimeout，v2 供应商 HTTP 超时改为 60 秒，总轮次上限仍为 120 秒，预设 1ms 故障项不变。配置由实际运行记录写入冻结清单，之后任何预算更改使清单失效。这不是修改 v1 分数；全部 6/30 秒报告保留。A06 修复后第一次 6/30 开发复验在 15/40 项因真实 ReadTimeout 停止，报告 `eval-dev-v2-attempt-1-calls6-partial.json` 为 14/15 完成、7/7 自动引用、0 禁止副作用、1 运行错误；测试库已正常清理。新版保留集此时从未运行。
